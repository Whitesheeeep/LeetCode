主要内容参看：[代码随想录-散列表总结](https://programmercarl.com/%E5%93%88%E5%B8%8C%E8%A1%A8%E6%80%BB%E7%BB%93.html#%E5%93%88%E5%B8%8C%E8%A1%A8%E7%90%86%E8%AE%BA%E5%9F%BA%E7%A1%80)

主要补充：

* 数组优点是在已知内容大小时能够快速的进行查找而且装填因子较高；但是数组的大小是受限制的，而且如果元素很少，而哈希值太大会造成内存空间的浪费。
* set 作为集合能够不受大小限制进行存储数据，但是只能存储一个 key。
* map 不仅能存储 key，也能存储对应的 value，但是所需存储空间更大。
