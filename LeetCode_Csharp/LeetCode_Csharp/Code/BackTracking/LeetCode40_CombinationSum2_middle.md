# LeetCode40_CombinationSum2_middle

## 易错点

首先，注意一个易错点，因为如果顺着之前的题目做过来，一定会导致掉进陷阱。因为直接递归的时候 startIndex + 1，而忘了去重，就会导致 bug。比如：[1,1,2,7]，target = 8，如果还是直接使用之前的（组合总和）思路去做，会导致出现 \[[1,7],[1,7]] 的结果出现，这样就出现了重复，因为会同时利用第一个 1 和第二个 1 进行两次递归，这样就会导致结果中出现重复。

## 去重思路

通过设置数组 used 标识数组中有哪些已经被用过的元素。
具体请看：[代码随想录](https://programmercarl.com/0040.%E7%BB%84%E5%90%88%E6%80%BB%E5%92%8CII.html)，里面很清楚的讲到了怎么查看树层是否重复，以及树枝是否重复：在 candidates[i] = candidates[i-1] 的情况下，used[i-1] = 1(true) 则树枝重复，=0（false）则树层重复。
