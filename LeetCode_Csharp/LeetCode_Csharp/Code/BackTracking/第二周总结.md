# 第二周总结

在 LeetCode131 了解到可以通过使用 startIndex 当做隔板进行切割题目的解答。

然后就是在进行回溯题目解答过程中，逐渐理解回溯：
回溯的终止条件可以当做是叶子节点的判断条件。回溯的 for 循环内部当做是边和节点，path.Add 即为进入节点的边，path.RemoveAt 即为离开节点的边，而再次 BackTracking 就是进入下一个节点。Add 到 BackTracking 中间部分就是该节点的区域。for 的 i++ 就是进入同一层的下一个节点。 for 中的(;判断部分;) 的判断部分可以进行剪枝。并且 i > startIndex 就是用于同层的处理，因为树枝之间的 startIndex 是直接重新赋值的。
